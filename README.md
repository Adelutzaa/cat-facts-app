# Animal Facts

Proiect simplu: HTML5 + CSS responsive + formular + integrare API
([Wikipedia REST API](https://en.wikipedia.org/api/rest_v1/), gratuit, fără cheie).

## Rulare în VS Code
1. Deschide folderul în VS Code (`File > Open Folder`).
2. Instalează extensia **Live Server**, apoi click dreapta pe `index.html` → *Open with Live Server*.
   (Merge și prin dublu-click pe `index.html`.)

## Fișiere
- `index.html` – structura (HTML5 semantic, formular)
- `style.css` – stil responsive (mobile-first, media queries)
- `script.js` – validare formular + `fetch` către API
